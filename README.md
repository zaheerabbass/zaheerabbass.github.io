# ZA Digital

Root site for **ZA Digital**, publisher of [KB Fit](https://zaheerabbass.github.io/kbfit-pages/).

This repository exists to serve **`app-ads.txt`** at the domain root, which is
where the IAB Tech Lab spec and Google AdMob require it to be published — the
root of the developer website listed on the store listing.

- **[app-ads.txt](./app-ads.txt)** — authorised digital sellers for ZA Digital's apps
- **KB Fit** — [site](https://zaheerabbass.github.io/kbfit-pages/) · [privacy policy](https://zaheerabbass.github.io/kbfit-pages/privacy.html)
